# Local Brain

Use this skill when provider calls fail or offline behavior is requested.

## When It Activates

- API/provider error, invalid key, or unavailable endpoint.
- Agent loop detects provider failure and switches to local fallback.

## What It Can Do

- System and workspace tasks using rule-based dispatch.
- Deterministic file and utility operations.
- Experience recall for previously solved prompts.

## Limits

- It is fallback-oriented, not full creative reasoning parity with large LLMs.
- Some advanced generation tasks may be concise compared to cloud models.
